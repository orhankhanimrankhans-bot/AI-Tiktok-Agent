# AI TikTok Agent — Agent Customization Guide

## Overview

This is a **9-stage automated faceless TikTok video generation pipeline** that orchestrates topic selection, script writing, visual planning, voice synthesis, video rendering, caption burning, and TikTok publishing.

### Current Architecture

**Entry Point**: Run the complete pipeline with:
```bash
python -m app.orchestrator
```

**LLM Backend**: **Ollama** (local, running on `http://localhost:11434/api/generate`)
- **Model**: `phi3:latest`
- **Implementation**: `ask_ollama()` helper in [orchestrator.py](app/orchestrator.py#L44) and [topic_manager.py](app/topic_manager.py#L7)
- Temperature tuning varies by module (0.1–0.7) based on determinism vs. creativity needs
- All requests use direct `urllib.request` (no external dependencies like OpenAI SDK)

**⚠️ NOTE**: If you see the argument "chatgpt" or receive requests to add ChatGPT/OpenAI support, the integration point is the `ask_ollama()` function. Both functions have identical signatures and return plain text. See [LLM Integration](#llm-integration) below.

## 9-Stage Pipeline Architecture

| Stage | Module | Input | Output | LLM Usage |
|-------|--------|-------|--------|-----------|
| 1. **Topic Selection** | [topic_manager.py](app/topic_manager.py#L60) | Previous topics (dedup) | Topic string | 400 max_tokens @ 0.7° (creative) |
| 2. **Script Generation** | [orchestrator.py](app/orchestrator.py#L95) | Topic | 6-section script (JSON) | 250 max_tokens per section @ 0.4° (consistent) |
| 3. **Visual Planning** | [visual_planner.py](app/visual_planner.py#L29) | Script | 3 scene descriptions | 60 max_tokens @ 0.7° (creative) |
| 4. **Voice Generation** | [voice/script_voice_pipeline.py](app/voice/script_voice_pipeline.py) | Script sections | Audio files (WAV) + timing | Piper TTS (no LLM) |
| 5. **Voice Validation** | [whisper_checker.py](app/whisper_checker.py) | Audio files | Accuracy % | Whisper (no LLM) |
| 6. **Pipeline Persistence** | [memory.py](app/memory.py) | Intermediate state | SQLite DB entry | No LLM |
| 7. **Video Rendering** | [video/renderer.py](app/video/renderer.py) | Scenes, audio, images | MP4 video (1080×1920, 30fps) | No LLM (FFmpeg) |
| 8. **Caption Burning** | [video/caption_renderer.py](app/video/caption_renderer.py) | Video + ASS captions | Final video with captions | No LLM (FFmpeg) |
| 9. **TikTok Upload** | [publishing/tiktok_publisher.py](app/publishing/tiktok_publisher.py) | Final video | Published post (URL) | OAuth2 token validation |

## Key Conventions & Patterns

### Script Section Format
Scripts are split into **6 sections** with strict word limits (enforced via truncation):

```python
SECTIONS = {
    "HOOK": 7,           # Attention-grabber (7 words)
    "SETUP": 10,         # Context
    "FACT": 10,          # Key information
    "EXPLANATION": 13,   # How/why it works
    "ENDING": 10,        # Conclusion
    "CTA": 5             # Call-to-action
}
```

**Generation Process** (see [orchestrator.py](app/orchestrator.py#L95-L180)):
1. Generate entire script with Ollama
2. Split by section labels (regex extraction)
3. Trim each section to word limit
4. Validate structure

### Visual Plan Format
3 scene descriptions (90 seconds total):
```json
{
  "scene_1": "description for first 30s",
  "scene_2": "description for second 30s", 
  "scene_3": "description for final 30s"
}
```

Generated by [visual_planner.py](app/visual_planner.py#L29) → stored in [output/pipeline/{topic}.json](output/pipeline/)

### State Flow

```
Topic (string)
  ↓ (ask_ollama + section splitting)
Script JSON {HOOK, SETUP, FACT, EXPLANATION, ENDING, CTA}
  ↓ (ask_ollama)
Visual Plan JSON {scene_1, scene_2, scene_3}
  ↓ (Piper TTS)
Audio files + timing metadata
  ↓ (Whisper validation)
Verified audio segments
  ↓ (FFmpeg compositing)
1080×1920 vertical video @ 30fps
  ↓ (FFmpeg ASS subtitles)
Final video with captions
  ↓ (OAuth2 token + HTTP)
TikTok post (URL + metadata)
```

All intermediate artifacts saved to [output/](output/) subdirectories.

## Module-by-Module Guidance

### Testing Individual Modules

Each module supports standalone execution:

```bash
# Generate new topic
python -m app.topic_manager

# Test voice generation
python -m app.voice_generator

# Test visual planning
python -m app.visual_planner

# Render video from JSON state
python -m app.video.renderer

# Burn captions
python -m app.video.caption_renderer

# TikTok OAuth flow
python -m app.publishing.tiktok_oauth
```

### Dependencies

**Python Packages** (inferred from code, no requirements.txt):
- `ollama` or `urllib` (built-in for Ollama client)
- `piper-tts` (voice synthesis)
- `openai-whisper` (transcription validation)
- `pillow` (image generation)
- `fastapi` + `uvicorn` (OAuth server)
- `sqlite3` (built-in)

**System Binaries**:
- `ffmpeg` and `ffprobe` (video encoding) — must be in system PATH
- `ollama` service (must be running on port 11434)

**Environment Variables**:
- `TIKTOK_CLIENT_KEY` (set for OAuth2)

### Database Schema

[memory.py](app/memory.py) provides:
- `get_all_videos()` → list of (id, topic, script, status, file_path)
- `insert_video(topic, script, status, file_path)`
- Topic deduplication via database query

## LLM Integration

### Current: Ollama

**Function Signature**:
```python
def ask_ollama(prompt: str, max_tokens: int = 250, timeout: int = 180) -> str:
    """
    POST to http://localhost:11434/api/generate
    Returns: plain text response
    """
```

**Usage Pattern** (all modules):
```python
response = ask_ollama(
    prompt=f"Generate topic about science",
    max_tokens=400,
    timeout=120
)
```

### Future: ChatGPT/OpenAI Integration

If switching to ChatGPT or OpenAI's API:

1. **Signature-Compatible Replacement**:
   ```python
   def ask_openai(prompt: str, max_tokens: int = 250, timeout: int = 180) -> str:
       # POST to api.openai.com/v1/chat/completions
       # Return .choices[0].message.content
   ```

2. **Update Import** in each module:
   - [orchestrator.py](app/orchestrator.py#L44) — import from config module
   - [topic_manager.py](app/topic_manager.py#L7)
   - [visual_planner.py](app/visual_planner.py#L29)

3. **Config Source** — Create `app/config.py`:
   ```python
   LLM_PROVIDER = "openai"  # or "ollama"
   OPENAI_API_KEY = os.environ.get("OPENAI_API_KEY")
   OPENAI_MODEL = "gpt-4"
   
   def ask_llm(prompt, max_tokens=250, timeout=180):
       if LLM_PROVIDER == "openai":
           return ask_openai(...)
       else:
           return ask_ollama(...)
   ```

4. **Test**: [agent_test.py](agent_test.py) has standalone LLM tests for validation.

## Development Workflow

### Typical Task Sequence

1. **Modify a module** → Edit Python file
2. **Test in isolation** → Run module directly:
   ```bash
   python -m app.{module_name}
   ```
3. **Validate in pipeline** → Run orchestrator:
   ```bash
   python -m app.orchestrator
   ```
4. **Check output** → Inspect [output/](output/) directory for artifacts

### Common Pitfalls

| Issue | Solution |
|-------|----------|
| "Ollama connection failed" | Ensure `ollama serve` is running on localhost:11434 |
| "FFmpeg not found" | Add FFmpeg to system PATH or install via package manager |
| "Script sections malformed" | Regex split in orchestrator.py expects section labels; validate prompt format |
| "Whisper validation fails" | Check audio quality, Piper model file exists at [models/en_US-lessac-medium.onnx](models/en_US-lessac-medium.onnx) |
| "TikTok token invalid" | Regenerate OAuth token via [publishing/tiktok_oauth.py](app/publishing/tiktok_oauth.py) |

### File Organization

```
app/
  orchestrator.py          ← Main pipeline coordinator
  topic_manager.py         ← Topic generation & dedup
  memory.py                ← SQLite database interface
```

## Recommendations for Agent Customization

### If Working on LLM Integration
- Modify LLM calls in 3 files: [orchestrator.py](app/orchestrator.py#L44), [topic_manager.py](app/topic_manager.py#L7), [visual_planner.py](app/visual_planner.py#L29)
- Validate via [agent_test.py](agent_test.py)
- Preserve word limits and section structure

### If Adding Features
- Follow modular pattern: Each module testable standalone
- Store state as JSON in [output/pipeline/](output/pipeline/)
- Use [memory.py](app/memory.py) for persistence
- Document Ollama (or new LLM) requirements in README

### If Debugging
- Check [output/](output/) directory for intermediate artifacts
- Enable verbose logging in orchestrator
- Test modules in isolation before running full pipeline
